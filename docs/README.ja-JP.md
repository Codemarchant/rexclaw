# Rexclaw Companions

<p align="center">
  [<a href="../README.md">English</a>] | 日本語
</p>

**あなたのマシンで生きる、アニメ調ボイスコンパニオン — xAI Grok Voice Realtime 駆動、APIキー持ち込み型（BYOK）。**

リップシンクし、表情を変え、ジェスチャーしながら答えてくれる 3D VRM
アバターと会話できます — 3D シーンの中を連れて歩くことも。セッションを
またいで育つ永続メモリ、Grok Imagine による画像・動画生成、ファイル添付
対応のテキストチャット、そして自前の MCP ツール連携も。モデル以外は
すべてローカルで動作します — データはディスク上の SQLite ファイルに
保存され、API キーがあなたのマシンの外に出ることはありません。

## 🚀 クイックスタート

### 💻 Windows アプリ — 推奨

[最新リリース](https://github.com/Codemarchant/rexclaw/releases/latest)から
`Rexclaw-<バージョン>-win.zip` をダウンロードして解凍し、`Rexclaw.exe` を
実行するだけ。完全自己完結型 — Python も Node も Docker も不要です
（Windows 10/11、64 ビット）。さらに、ブラウザ版にはないデスクトップ専用
機能が含まれます：ポップアウトのデスクトップマスコット（ゴーストモード・
トレイ操作・トランスクリプトウィンドウ）と、ワンクリックの VR / HTTPS
デバイスアクセスです。

### 🛠 ソースから

```bash
./run.sh        # Linux / macOS / WSL
run.bat         # Windows
```

初回実行時にすべて自動セットアップされ（Python venv、バックエンド依存、
フロントエンドビルド）、http://localhost:8990 が開きます。2 回目以降は
すぐに起動します。必要環境：Python 3.10 以上と Node.js。

Windows では上記のパッケージ版アプリのほうが簡単です — `run.bat` は主に
開発用、またはデスクトップシェルなしでブラウザ版を動かすためのものです。

アプリ内での手順：**設定 → xAI API キーを貼り付け**（[x.ai/api](https://x.ai/api)
で取得）→ **Voice** タブへ → コンパニオンを選択 → **Start**。

### 🐳 Docker

```bash
git clone https://github.com/Codemarchant/rexclaw.git && cd rexclaw
docker compose up -d                          # → http://localhost:8990
docker compose pull && docker compose up -d   # 最新リリースへ更新
```

状態（設定・履歴・画像）はすべて `/data` ボリュームにあるため、更新で
データが消えることはありません。同じネットワークのスマートフォン・
タブレット・VR ヘッドセットからアクセスするには、`docker-compose.yml`
で HTTPS モードを有効にしてください（ポートマッピングを `"8990:8990"`
に、`environment:` に `REXCLAW_SSL=1` を追加）— 詳細は
[VR の使い方](#-vr-の使い方) を参照。

## 🎭 カスタムアバター — アバターパック

すべてのコンパニオンにはアバターがあります — 衣装・ジェスチャークリップ・
シーン背景をオプションで持つ VRM キャラクターです。作り方は 2 通り：
**アプリ内エディタ**（いちばん簡単）、またはディスクに**パックフォルダ**を
置く方法（共有・上級者向け）。

### アプリ内で — Avatars タブ

**New avatar** をクリックして名前を付け、**メイン VRM**（唯一の必須ファイル）
をアップロードします。その後、任意で以下を追加できます：

- **待機アニメーション**（VRMA）
- **衣装** — 同じキャラクターの別 VRM。それぞれに説明を付けると、モデルが
  いつ着替えるべきか判断します
- **カスタムジェスチャー** — トリガー名と説明付きの VRMA クリップ
  （ループ再生も可）
- **背景** — 内蔵プリセット、アップロード画像、または **GLB 3D シーン**
  （スケール／X-Y-Z オフセット／Y 回転の調整付き）

保存したら、コンパニオン編集画面の **Avatar** ドロップダウンから選択します。
自作アバターはいつでも編集・削除できます。同梱の 5 体は読み取り専用です
（調整したい場合は新しいアバターを作成してください）。ファイルは追加した
その場でパックにアップロードされ、保存時にフォルダ名がアバター名になります
（エディタには `data/avatars/<名前>/` と表示されます）。

**共有アセットライブラリ：** ファイルを `data/assets/` に一度置けば、各
アップロード欄の **ライブラリ…** ドロップダウンから選択でき、どのアバター
も同じ 1 ファイルを参照します（同梱のシーンやジェスチャークリップも選択
できます）。

### パック形式（共有・手書き作成）

内部的には、各アバターは `avatar.json` マニフェストとファイル群が入った
ただのフォルダです — エディタが読み書きしているのもこれで、Avatars タブの
**エクスポート**/**パックをインポート** ボタンが zip 化・展開しているのも
これです（[エクスポートとインポート](#-エクスポートとインポート)参照）。
ボタンなしのフォルダ運用も従来どおり：パックフォルダを `data/avatars/` に
置いて再起動するか、手書きで作成できます。`assets/avatars/` の
同梱パック 5 つが実例を兼ねています。

> **Windows デスクトップアプリの場合：** パッケージ版はデータを
> `%APPDATA%\Rexclaw\data\` に保存します。カスタムパックは
> `%APPDATA%\Rexclaw\data\avatars\<パック名>\` に置いてください
> （このパスをエクスプローラーのアドレスバーに貼り付ければ開けます）。
> それ以外はすべて同じです。

```
data/avatars/Kira/
├── avatar.json
```

### VRM モデルの入手先

- **[VRoid Studio](https://vroid.com/studio)** — pixiv の無料キャラクター
  メイカー（Windows/macOS/Steam）。スライダーでアニメキャラを造形し、服を
  ペイントして、そのまま `.vrm` にエクスポート。*自分だけの*コンパニオンを
  作る最短ルートです — 衣装は同じキャラクターの別エクスポートを使うだけ。
- **[VRoid Hub](https://hub.vroid.com)** — 何千体もの既製 VRM キャラクター
  をダウンロードできます。パックに同梱する前に、**各モデルの利用条件を必ず
  確認**してください（改変・再配布・商用利用の可否はクリエイターがモデル
  ごとに設定しています）。
- **[BOOTH](https://booth.pm)** — pixiv のマーケットプレイス。より
  作り込まれた、あるいは限定的なアバターを求めるなら、有料（と無料）の
  VRM アバターが豊富にあります。

アニメーションクリップは `.vrma` 形式です — 同梱ジェスチャーパック
（pixiv の VRoid Project Motion Pack）が組み込み分をカバーし、パックで
アバターごとのカスタムクリップを追加できます。

## 📦 エクスポートとインポート

すべて持ち運べます。それぞれのタブから：**Companions** —
ダウンロードアイコンでコンパニオンを zip 1 つにエクスポート（設定に加え、
アバターパック・ロア・メモリ・会話履歴・ハートビートをそれぞれトグルで選択。
メモリ・会話履歴・ハートビートは既定でオフ — キャラクターではなく、あなたに
関する内容だからです。ハートビートは常に無効状態でインポートされ、確認して
から有効化できます）、
**インポート** で新しいコンパニオンとして再現。何も上書きされず（インポートしたものを削除しても
元には影響しません）、認証シークレットを含みうる MCP 接続は決して
エクスポートされません。**Avatars** — どのアバターも自己完結したパック zip
としてエクスポートでき、**パックをインポート** は zip（手動で zip 化した
パックフォルダも可）を受け付けます。**Memories** — バージョン付き JSON
ファイルで、コンパニオンの絞り込みに従います。再インポート時は重複を
スキップします。

## 🥽 VR の使い方

ヘッドセット自身のブラウザ（Quest、Pico など）でアプリを開き、キューブ
ボタンを押せばコンパニオンと VR で並んで立てます。パススルー対応の
ブラウザなら同じボタンで**複合現実（MR）**に入れます — 現実の部屋に
コンパニオンが現れ、ヘッドセット内パネルでバーチャル／パススルーを
切り替えられます。WebXR とマイクはセキュアな（HTTPS）オリジンでしか
動作しないため、アプリには HTTPS モードが組み込まれています。必要なのは
ヘッドセットと PC が同じ WiFi にあることだけです。

この HTTPS モードは**スマートフォンやタブレット**も解放します：同じ
WiFi 上のどのデバイスからでも同じ URL を開けて、HTTPS 配信だからこそ
マイクが動作します — スマホからフルの音声通話ができ、アプリとしての
インストール（ホーム画面に追加）も可能です。HTTP のままでは他のデバイス
からは閲覧とテキストチャットしかできません。

**Windows アプリ（推奨）：**

1. **設定 → VR ヘッドセット・他のデバイス（HTTPS）** をオンにします。
   アプリのサーバーが HTTPS モードで再起動して画面が再読み込みされます。
   Windows ファイアウォールに聞かれたら許可してください。
2. 設定画面に `https://192.168.1.42:8990/` のようなアドレスが表示され
   ます — ヘッドセットのブラウザでこれを開き、初回のみ表示される
   証明書の警告を承認します（詳細設定 → アクセスする）。
3. キューブボタンを押します。VR に入ると同時に会話が自動的に開始
   （または再開）されます。

**ソースから（`run.sh` / `run.bat`）：**

1. HTTPS + LAN を有効にして起動します：
   - Linux/macOS: `REXCLAW_SSL=1 REXCLAW_HOST=0.0.0.0 ./run.sh`
   - Windows: `set REXCLAW_SSL=1` → `set REXCLAW_HOST=0.0.0.0` →
     `run.bat` — WSL ではなくネイティブ Windows で実行してください
     （WSL の仮想ネットワーク内のサーバーには LAN のデバイスから
     到達できません）。
2. PC の LAN アドレスを確認し（Windows は `ipconfig`、Linux は
   `ip addr`）、ヘッドセットのブラウザで `https://<PCのIP>:8990` を
   開いて証明書の警告を承認します。
3. キューブボタンを押します。

**Docker：**

1. `docker-compose.yml` のポートマッピングを `"8990:8990"` に変更し、
   `environment:` に `REXCLAW_SSL=1` を追加します。
2. ヘッドセットのブラウザで `https://<ホストのIP>:8990` を開き、
   証明書の警告を承認します。
3. キューブボタンを押します。

自己署名証明書は `data/certs/` に一度だけ生成されます。自前の証明書を
使う場合は `REXCLAW_SSL_CERT` / `REXCLAW_SSL_KEY` を設定してください。
アプリには認証がないため、LAN 配信は信頼できるネットワークでのみ有効に
してください。（PCVR / OpenXR 環境でも動作します — Windows アプリの
キューブボタンが VR 対応ブラウザのウィンドウでシーンを開きます — が、
推奨は上記のヘッドセットブラウザの流れです。）

## 🔌 リモート MCP 接続

リモート MCP サーバーを接続して、コンパニオンにツールを追加できます：
**Companions → Edit → Remote MCP connections**。各接続には、サーバー
ラベル、エンドポイント URL、任意の Bearer トークン（書き込み専用で保存 —
ブラウザに返されることはありません）、任意の追加ヘッダー、許可ツールの
ホワイトリスト、音声／テキストセッションごとのトグルを設定します。

仕組み：接続はセッションのツールリストに注入され、**xAI のサーバーが MCP
エンドポイントを直接呼び出します** — そのため URL は **HTTPS で公開到達
可能**である必要があります。

## 💰 xAI のコスト最適化

- **音声は「話している時間」ではなく「通話が開いている時間」で課金されます** —
  `grok-voice-think-fast-1.0` で約 $0.05/分、2.0 で約 $0.08/分。さらに
  **グループ通話ではコンパニオンごとに個別の接続が課金されます。** 3 人が参加して
  いれば、発話の有無にかかわらずおよそ 3 倍になります。**ミュートしても止まり
  ません。** 最小化して放置せず、通話は終了してください。（発話のない状態が
  15 分続くと、xAI 側から通話が切断されます。）
- **会話の再開は、未要約の履歴 1 メッセージあたり約 $0.004 かかります。**
  コンパニオンの記憶を戻すため履歴が xAI に再送されるためです。要約が行われると
  この件数はリセットされ、1 件ずつ再送されるのは前回の要約以降に積み上がった分
  だけです。したがって 250 メッセージ分が溜まっていれば、**再開するたびに約 $1**
  となります。

後者のコストは、2 つの設定で抑えられます。

- **設定 → コンテキスト管理 → 音声の要約しきい値** — 低くすると会話がより頻繁に
  要約されるため、再開までに溜まる未要約の履歴が減ります。長く続く会話ほど効果が
  あります。その代わり要約の呼び出しが増え、会話のより多くの部分がそのままの言葉
  ではなく要約として引き継がれます。
- **設定 → コスト最適化 → 再開時に古い履歴をまとめる** — 古いメッセージを数百件
  ではなく 1 件にまとめ、約 $1 が 1 セント未満になります。すべての語句はそのまま
  送信され、変わるのは形だけなので、まとめられた部分の記憶がやや曖昧になる可能性
  があります。直近のやり取り（既定で 20 件）はそのまま保持されます。既定では
  オフですが、短いやり取りのために会話を頻繁に開いたり閉じたりする場合はおすすめ
  です — その使い方では履歴の再送が料金の大部分を占めるためです。長時間の通話では
  分単位の料金の方が大きく、影響はずっと小さくなります。

ツール（ウェブ検索・X 検索・MCP・画像/動画生成）、テキストチャット、
バックグラウンド要約は別途課金されます。実際の利用額：
[xAI コンソール](https://console.x.ai) ／ 料金：[xAI 料金ページ](https://docs.x.ai/docs/models)。

## 🛠 開発

```
server/   FastAPI + SQLite バックエンド   → 編集して再起動（または uvicorn --reload）
web/src/  React + Vite フロントエンド     → 編集後 npm run build
data/     DB・画像・アバターパック        → ただのデータ、ビルド不要
```

- フロントエンドのホットリロード開発：`cd web && npm run dev` →
  http://localhost:5990 （uvicorn バックエンドも**起動している必要が
  あります** — Vite が `/api`・`/assets`・`/files` をポート 8990 に
  プロキシします）。
- IDE デバッグ設定（PyCharm）：uvicorn CLI の代わりに `debug_server.py`
  を実行してください。
- データベースは `data/rexclaw.sqlite3` のプレーンな SQLite です — お好みの
  クライアントで開けます（PyCharm の Database パネル、DB Browser for
  SQLite、`sqlite3`）。

### アーキテクチャ

```
browser ── WebSocket ──► xAI Realtime API   （音声 — 短命トークンで直接接続）
browser ── fetch ──────► FastAPI :8990      （セッション・メモリ・画像生成・設定）
FastAPI ── SQLite + ローカルファイル        （data/rexclaw.sqlite3, data/files/）
```
